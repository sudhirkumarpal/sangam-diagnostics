# Sangam Diagnostics — Diagnostic Website & Installable Web Application (PWA)

See the root [`README.md`](../README.md) for full project documentation, architectural overview, authentic clinic details, test credentials, and deployment guides.

### Local Development Commands
```bash
npm run dev     # Starts local development server on http://localhost:3000
npm run build   # Compiles production bundle with Turbopack & generates static pages
npm run start   # Runs the production server
```
